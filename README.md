AutoCare es una aplicación diseñada para simplificar el mantenimiento y la gestión de vehículos. Permite a los usuarios llevar un registro detallado de sus servicios, recibir recordatorios de mantenimiento preventivo y gestionar el historial de reparaciones, todo desde una interfaz intuitiva y accesible.

## ✨ Características Principales

- **Gestión de Vehículos:** Registra múltiples vehículos con sus datos específicos (marca, modelo, año, kilometraje).
- **Recordatorios Automáticos:** Alertas programadas para cambios de aceite, rotación de neumáticos, renovación de seguro y mantenimiento general.
- **Historial de Servicios:** Registro completo de reparaciones y mantenimientos pasados, incluyendo costos y notas.
- **Interfaz Intuitiva:** Diseño limpio centrado en la experiencia del usuario (UX) para facilitar la navegación.
